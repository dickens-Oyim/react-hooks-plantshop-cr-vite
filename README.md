# 🌱 Plantsy

Plantsy is a React application for managing a plant shop. It connects to a JSON backend (`http://localhost:6001/plants`) and allows users to view, add, search, and toggle stock status for plants.

---

##  Features
- **See all plants on page load**  
  Fetches plant data from the backend and renders them dynamically.
- **Add a new plant**  
  Submit the form to create a new plant via a POST request and update state.
- **Mark a plant as sold out**  
  Toggle stock status with conditional rendering in each PlantCard.
- **Search plants by name**  
  Filter plants in real time using the search bar.
